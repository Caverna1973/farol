# Segurança · Security

## Encontrou uma falha no site ou no protocolo?

Escreva para **dasilveira.araujo@proton.me** com o assunto `[SECURITY]`.

- Descreva a falha e como reproduzir.
- **Não** abra uma issue pública antes de conversarmos.
- **Não** envie dados reais de terceiros, credenciais ou código malicioso funcionando.

Respondemos em até 7 dias. Corrigimos e, se você quiser, damos o crédito público.

## Fora do escopo

Este endereço não é para relatos de incidentes com agentes de IA. Para isso, veja o [`PROTOCOL.md`](PROTOCOL.md).

---

Found a vulnerability in the site or protocol? Email **dasilveira.araujo@proton.me** with subject `[SECURITY]`. Please don't open a public issue first, and don't send real third-party data, credentials or working malicious code. We aim to reply within 7 days and will credit you if you wish.
