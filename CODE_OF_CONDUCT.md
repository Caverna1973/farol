# Código de conduta · Code of conduct

O Farol segue o espírito do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

**Em resumo:**
- Trate todas as pessoas com respeito, inclusive quem discorda de você.
- Critique ideias, não pessoas.
- Nada de assédio, discriminação ou exposição de dados de alguém.
- Não use o projeto para ajudar agentes a evadir supervisão humana.
